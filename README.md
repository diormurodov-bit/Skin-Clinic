# Skin—Clinic (HTML / CSS / JS Edition)

Автономная статическая версия интернет-магазина **Skin—Clinic**, подключённая к **Sandbox Shop API v1.0** (`https://api.wepro.uz/sandbox-shop`), с локальными брендовыми фотографиями, логотипом в WebP (`assets/img/logo.webp`) и видеопрезентацией в разделе Checkout (`assets/video/presentation.mp4`).

## Структура проекта

- `index.html` — главная страница (Hero, Best sellers, Shop by category, Featured products)
- `products.html` — каталог товаров с плавающим фильтром на ПК и мобильной шторкой `$0–$100`
- `product.html` — страница товара, счётчик 1–20, отзывы (`All Reviews`), модальное окно `Leave a comment` и `Thank you!`
- `bag.html` — корзина с переходом на страницу оформления заказа (`checkout.html`)
- `checkout.html` — оформление заказа + компактная карточка видеопрезентации (без значка на превью; мини-просмотр без звука при наведении/касании; при клике открывается на весь экран с защитой от скачивания, кнопкой звука, выбором скорости `0.5×–2×` и перемоткой)
- `login.html` / `register.html` — авторизация и регистрация
- `profile.html` — личный кабинет и выход
- `css/style.css`, `js/`, `assets/`, `robots.txt`, `sitemap.xml`, `manifest.json`, `humans.txt`, `rd.txt`, `package.json`
